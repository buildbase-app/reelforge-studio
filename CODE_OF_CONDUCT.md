# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
It applies in every project space (issues, pull requests, discussions, reviews)
and to people and to AI agents acting on someone's behalf. The person running an
agent is responsible for what it posts.

In short: be respectful and constructive, assume good intent, no harassment,
discrimination or personal attacks, and no spam (including unsolicited automated
or AI-generated issues, comments or pull requests).

## Enforcement

Report unacceptable behaviour privately to the maintainers at
<https://reelforge.buildbase.app/contact> (or a private security advisory if it
involves a security issue). Reports are handled confidentially.

Maintainers may edit or remove comments, close issues and pull requests, and
temporarily or permanently block anyone who breaks this code, following the
Contributor Covenant's enforcement guidelines (correction, warning, temporary
ban, permanent ban).
