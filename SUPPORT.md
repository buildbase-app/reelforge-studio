# Getting help

- **How-to questions and FAQ:** <https://renderweld.com/help>
- **Bugs and feature requests:** open an issue with the issue forms (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Security problems:** report privately, never in public (see
  [SECURITY.md](SECURITY.md)).
- **Licences, purchases, commercial and partnership questions:**
  <https://renderweld.com/contact>

Issues are for problems with the code and its docs. Please don't use them for
general questions, sales or support requests; they may be closed and pointed here.
