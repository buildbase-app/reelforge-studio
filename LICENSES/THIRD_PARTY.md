# Third-party inventory

Generated by hand on 2026-11-21 from `pnpm-lock.yaml` / installed packages.
Direct runtime dependencies only. The complete list with transitive
dependencies and OS packages is the CycloneDX SBOM CI writes for every
release image (artifact `sbom-<arch>`; 591 components on 2026-11-21), and a
licence review of it is still to do before a release. The storage SDKs added for #27 bring
about 110 transitive packages, all Apache-2.0, MIT or BSD-3-Clause (checked
from the installed `package.json` files on 2026-11-21; no LGPL/GPL).

**Release image (issue #26, D-040):** dependencies are installed from npm with
pnpm (`--prod`, lockfile), unmodified and **not bundled or minified**; only
source maps, type declarations and changelogs are deleted from `node_modules`.
Build-only tools (`@remotion/bundler`/Webpack/Rspack, Vite, the Motion Canvas
build plugins) and Remotion itself are devDependencies and are not in the image. The image ships
`LICENSE.md`, `NOTICE` and this file under `/app`.
